# PathForge AI — Enterprise AI Career Intelligence & Trajectory Platform

PathForge AI is an end-to-end, production-grade AI career co-pilot platform powered by Google Gemini AI, Express, MongoDB Atlas, and React. It equips job seekers and professionals with real-time resume auditing, ATS optimization, 8-week structured learning roadmaps, real-time AI mock interviews, recruiter simulator screenings, opportunity radar scans, and executive CEO mode trajectory execution.

---

## 🌟 Key Platform Features

- ⚡ **Secure Single-Sign-On & Cookie Auth**: Double HTTP-only cookie authentication with Access & Refresh Tokens, Refresh Token Rotation (RTR), and automatic silent session updates.
- 📄 **Smart Resume Parser & Manager**: Multi-resume upload via Cloudinary, PDF text extraction, experience schema parsing, and dynamic resume versioning.
- 🎯 **Real-time ATS Analyzer**: Deep ATS compatibility scoring against job descriptions, keyword extractions, section breakdown, and prioritized improvement action items.
- 💼 **AI Job Matcher Matrix**: Dynamic alignment matrix matching candidates against top tech roles, highlighting missing skills and competitive positioning.
- 🗺️ **Personalized Learning Roadmaps**: Week-by-week learning paths generated by Gemini AI with official documentation links, milestone tracking, and task completion checklists.
- 🤖 **Interactive AI Mentor & Mock Interviews**: Voice/text recruiter mock interview simulations with granular scoring feedback on technical accuracy, clarity, and communication.
- 🎯 **Recruiter Simulator**: Enterprise screening simulator evaluating candidate resumes against target company rubrics (FAANG/M7 standards).
- 👑 **AI CEO Mode**: High-level strategic career planning, milestone delegation, and executive decision-making interface.

## 🏗️ Technology Stack

### **Frontend (`/client`)**
- **Core Framework**: React 19, React Router DOM v7
- **Styling & UI**: Tailwind CSS, Glassmorphism design system, Framer Motion animations
- **Forms & Validation**: React Hook Form, Zod schema validation
- **Data Visualization & Icons**: Recharts, Lucide React
- **HTTP Client**: Native Fetch API (NO Axios dependency) with automatic 401 token refresh interceptor and timeout abort handling

### **Backend (`/server`)**
- **Runtime & Framework**: Node.js (ES Modules), Express.js
- **Database & ODM**: MongoDB Atlas, Mongoose v8
- **AI Engine Integration**: `@google/generative-ai` (Google Gemini 3.1 Flash Lite)
- **Security & Middleware**: Helmet, CORS, Express Rate Limit, Express Mongo Sanitize (NoSQL Injection Protection), Cookie Parser, JsonWebToken, BcryptJS
- **File Uploads & Storage**: Multer, PDF-Parse, Cloudinary SDK

## 🚀 Quick Start & Local Setup

### **Prerequisites**
- Node.js (v18.x or higher)
- MongoDB Atlas Instance or local MongoDB
- Google Gemini API Key

---

### 1. Environment Setup

Create `.env` in `server/`:

```env
PORT=5000
NODE_ENV=development
FRONTEND_URL=http://localhost:5173
MONGO_URI=mongodb+srv://user:password@cluster.mongodb.net/pathforge?retryWrites=true&w=majority
JWT_ACCESS_SECRET=your_super_secret_jwt_access_key_at_least_32_characters
JWT_REFRESH_SECRET=your_super_secret_jwt_refresh_key_at_least_32_characters
ACCESS_TOKEN_EXPIRY=15m
REFRESH_TOKEN_EXPIRY=7d
GEMINI_API_KEY=your_google_gemini_api_key
GEMINI_MODEL=gemini-3.1-flash-lite
CLOUDINARY_CLOUD_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_key
CLOUDINARY_API_SECRET=your_cloudinary_secret
```

Create `.env` in `client/`:

```env
VITE_API_URL=http://localhost:5000/api/v1
```

---

### 2. Start Backend & Frontend

```bash
# Terminal 1 - Backend
cd server
npm install
npm run dev

# Terminal 2 - Frontend
cd client
npm install
npm run dev
```

## 🌐 Production Deployment

### **Backend (Railway)**
1. Deploy `server/` root folder to Railway.
2. Configure Environment Variables (`MONGO_URI`, `JWT_ACCESS_SECRET`, `FRONTEND_URL`, `GEMINI_API_KEY`, etc.).
3. Railway automatically runs `npm start` (`node server.js`).
4. Set Health Check path to `/health`.

### **Frontend (Vercel)**
1. Deploy `client/` root folder to Vercel.
2. Framework Preset: **Vite**.
3. Set Environment Variable: `VITE_API_URL=https://your-railway-backend.up.railway.app/api/v1`.

## 🔒 Security Highlights

- **Trust Proxy Protection**: Forwarded IP rate limiting via Railway load balancer.
- **NoSQL Injection Shield**: Payload keys sanitized via `express-mongo-sanitize`.
- **HTTP-Only Cookie Isolation**: Access and Refresh tokens isolated from JavaScript access (`SameSite=None`, `Secure` in production).
- **Prompt Injection Defense**: All user inputs fed to Gemini AI wrapped in rigid context boundaries with untrusted data flags.
