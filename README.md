# PathForge AI — Enterprise AI Career Intelligence & Trajectory Platform

PathForge AI is an end-to-end, enterprise-grade AI career platform powered by Google Gemini AI, Express, MongoDB, and React. It equips job seekers and professionals with real-time resume auditing, ATS optimization, 8-week structured learning roadmaps, real-time AI mock interviews, candidate twin simulations, and executive CEO mode execution.

---

## 🌟 Key Platform Features

- ⚡ **Luxury Authentication Experience**: Seamless single-entry authentication experience with floating glass navbar, neural flow animations, and tabbed login/registration.
- 📄 **Smart Resume Parser & Manager**: Multi-resume upload via Cloudinary, structured PDF text extraction, experience parsing, and dynamic versioning.
- 🎯 **Real-time ATS Analyzer**: ATS compatibility scoring against target Job Descriptions, key keyword matching, section-by-section breakdown, and actionable optimization tips.
- 💼 **AI Job Matcher Matrix**: Dynamic alignment matrix matching candidates against top tech roles, highlighting skill gaps and competitive positioning.
- 🗺️ **Personalized 8-Week Roadmaps**: Dynamic week-by-week learning paths generated by Gemini AI with curated resources, actionable projects, and milestone tracking.
- 🤖 **Interactive AI Mentor & Mock Interviews**: Context-aware career coaching and automated voice/text recruiter mock interview simulations with granular scoring feedback.
- 🔮 **Career Twin & Evolution Simulator**: Predictive 12-month trajectory simulation modeling salary growth, market readiness, and career advancement paths.
- 👑 **AI CEO Mode**: High-level strategic career planning, milestone delegation, and executive decision-making interface.

---

## 🏗️ Technology Stack

### **Frontend (`/client`)**
- **Core Framework**: React 19, React Router DOM v7
- **Styling & UI**: Tailwind CSS, Vanilla Glassmorphism utilities, Framer Motion animations
- **Forms & Validation**: React Hook Form, Zod schema validation
- **Icons & Data Visualization**: Lucide React, Recharts
- **HTTP Client**: Axios with automatic JWT interceptors & refresh handlers

### **Backend (`/server`)**
- **Runtime & Server**: Node.js, Express.js
- **Database & ODM**: MongoDB Atlas, Mongoose v8
- **AI Engine Integration**: `@google/generative-ai` (Google Gemini 1.5 Flash / Pro)
- **Security & Middleware**: Helmet, CORS, Express Rate Limit, Cookie Parser, JsonWebToken, BcryptJS
- **File Uploads & Parsing**: Multer, PDF-Parse, Cloudinary SDK

## 🚀 Quick Start & Installation

### **Prerequisites**
- Node.js (v18.x or higher)
- npm or yarn
- MongoDB Instance (Local or MongoDB Atlas)
- Google Gemini API Key

---

### 1. Environment Setup

Create a `.env` file inside the `server/` directory:

```env
PORT=5000
NODE_ENV=development
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
JWT_REFRESH_SECRET=your_jwt_refresh_secret_key
GEMINI_API_KEY=your_google_gemini_api_key
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
CLIENT_URL=http://localhost:5173
```

---

### 2. Start the Backend Server

```bash
cd server
npm install
npm run dev
```

The Express API server will start on `http://localhost:5000`.

---

### 3. Start the Frontend Client

```bash
cd client
npm install
npm run dev
```

The Vite dev server will start on `http://localhost:5173`.

## 🔒 Security & Code Standards

- **JWT Authentication**: HttpOnly cookie-based token authentication with silent refresh token rotation.
- **AI Resiliency**: All Google Gemini service calls implement robust JSON sanitizers, schema validation, and structured fallback responses to prevent runtime failure.
- **Security Protocols**: Protected via `helmet`, HTTP rate-limiting (`express-rate-limit`), input validation (`zod`), and CORS origin restriction.
